The idea

This group collects several confirmed builds: cutting boards, custom cornhole boards, a giant stacking game and mountain-shaped table numbers. Their shared aspiration is practical making—objects that are handled, played with or used at a gathering—while learning new tools and techniques. They should eventually become individual visual entries. For now, grouping them preserves the breadth without pretending the missing photos and specifications have been recovered.

How it works

This is a physical build, not software to launch locally. Its use is the object’s actual purpose described above.

Present actual whole-object and detail photographs when available; no generated illustration is a substitute for an evidence photo.

Inside the build

Functional woodworking

Cutting boards belong to a different use case from signage or games. The fact of the build is confirmed; the wood species, glue-up, dimensions and finish are not.

Making for play

Cornhole boards and a giant stacking game connect fabrication to repeated physical use. The story can show how the actual objects are used without inventing regulation dimensions, construction standards or durability test results.

Small repeated objects

Mountain-shaped table numbers link shape, identification and event use. Their pattern, quantity, cutting process and numbering method need actual images or build notes before they are described.

What I learned

Use changes the design problem

Food contact, play and event identification create different practical questions. This is a way to discuss varied making interests without claiming every project used the same process.

Keep small projects in the archive

A useful object does not need a commercial launch to belong in a portfolio. These builds show the range of hands-on work alongside the larger software stories.
