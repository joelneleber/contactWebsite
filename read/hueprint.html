HuePrint

Scanned blueprints toward interactive 3D residential models.

ReactTypeScriptReact Three FiberThree.js

The idea

HuePrint explores the gap between a flat professional building plan and a space someone can understand in three dimensions. The original scope imagined a contractor uploading a blueprint, walking a client through the resulting house, swapping paint, siding, roofing and window finishes, and exporting the selections. That larger ambition made it a useful learning project across file processing, computer vision, geometry and browser rendering. The surviving implementation is a partial pipeline toward that goal; it is not evidence of a finished automatic design or material-selection product.

How it works

Upload one PDF, PNG or JPEG blueprint. The interface validates the file before rendering or converting it into pixel data.

Review the preprocessed image and confirm a drawing scale. Automatic scale detection is a placeholder suggestion, so this manual step is essential.

Run feature detection and inspect the overlay before continuing. Current source offers client-side Hough detection plus optional server-backed vector, text and ML paths.

Continue into a Three.js model preview and orbit, pan or zoom around the detected geometry. This preview visualizes the detector's output; it does not independently certify a complete or accurate house.

Inside the build

From pixels to candidate walls

The current client path preprocesses ImageData with luminance conversion and contrast stretching, then runs a custom Canny pipeline: Gaussian blur, Sobel gradients, nonmaximum suppression and hysteresis edge tracking. A Hough-based wall detector and segment merging turn that edge map into candidate geometry. This is a concrete implementation story about replacing incompatible libraries with a small inspectable algorithm, not a claim of production-grade architectural recognition.

Keeping drawing space and world space separate

Scale parsing and coordinate-mapping utilities translate pixel measurements into world units. Wall endpoints are clustered with union-find before geometry is assembled. React Three Fiber components then position walls, floors and ceilings, with conditional CSG openings for detected doors and windows. Lazy loading keeps the 3D dependency chain out of the initial upload interface.

A browser pipeline with explicit review points

The workflow is a state machine spanning upload, PDF page selection, conversion, preprocessing, scale, detection and modeling. Current uncommitted code adds multiple detection modes and fallbacks; the portfolio should distinguish that inspected working tree from the last committed February snapshot. Source also retains older OpenCV worker scaffolding, so the active hook implementation is more reliable evidence than a stale architectural summary.

What I learned

Computer vision has failure modes that a UI must expose

The interesting learning topic is not simply detecting lines. Real plans contain text, title blocks, double wall edges, broken segments and different scales. The detector overlay and manual scale step make those assumptions visible. In the synthetic capture, only two walls were detected from a plan containing several more. The resulting incomplete model is useful evidence of the project's actual limit, rather than something to hide behind an attractive 3D screenshot.

Geometry needs topology and units, not just boxes

Endpoint snapping, segment orientation, opening placement and unit conversion all affect whether neighboring walls meet. This project offers a practical way to discuss moving from image-processing output to a stable scene graph. It also illustrates that rendering a model and reconstructing the correct building are different achievements.

Scope can remain ambitious while the artifact stays honest

First-person walkthroughs, live material customization and a material list belong to the documented aspiration. They should appear as intended next steps, not current capabilities. The strongest personal-site story is the attempt to connect these disciplines and what the intermediate pipeline reveals about that problem.
